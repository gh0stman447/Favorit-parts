# Поиск автозапчастей

React-приложение с Redux Toolkit для двухшагового API Favorit Parts.

1. Запустите `npm run dev`.
2. При необходимости скопируйте `.env.example` в `.env.local` и укажите свой ключ покупателя.

Первый запрос ищет бренды по артикулу, второй — предложения и аналоги выбранного бренда. Локально Vite и на Netlify запросы проксируются через `/api`, поэтому HTTPS-сайт не сталкивается с mixed content.
