# Поиск автозапчастей

React-приложение с Redux Toolkit для двухшагового API Favorit Parts.

1. Запустите `npm run dev`.
2. При необходимости скопируйте `.env.example` в `.env.local` и укажите свой ключ покупателя.

Первый запрос ищет бренды по артикулу, второй — предложения и аналоги выбранного бренда. В development запросы идут напрямую к API: сервис разрешает CORS. При размещении сайта по HTTPS настройте прокси, чтобы избежать mixed content, и укажите его URL в `VITE_FAVORIT_API_URL`.
